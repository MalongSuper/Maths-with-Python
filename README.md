# Mathematics with Python

This repository is a **collection of Python code for solving and exploring mathematical problems**, covering both fundamental mathematical concepts and computational methods.

## Contents

The repository covers:

* **Linear Algebra and Matrices** using NumPy
* **Calculus** using SciPy and SymPy
* **Discrete Mathematics**
* **Probability and Statistics** implemented from studied formulas and concepts
* **Numerical Methods** implemented from scratch
* **Optimization** using Google OR-Tools
* Other mathematical problems, examples, and computational techniques

The goal is to use Python as a tool for **understanding, implementing, and solving mathematical concepts**, ranging from basic calculations to more advanced computational methods.

## Notes

* Some implementations are written **from scratch** to demonstrate the underlying mathematical concepts.
* External libraries such as **NumPy, SciPy, SymPy, and Google OR-Tools** are used where appropriate.
* The repository may be expanded with additional mathematical topics and implementations over time.
